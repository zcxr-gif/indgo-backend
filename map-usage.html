Usage vs limit

Counter resets on the 1st of each month (UTC). Mapbox's free web tier is 50,000 loads/month — the limit can never be set above it. The count is persisted to the database, so it survives restarts and redeploys.

The switches

Force the free map for everyone

Kill switch: every visitor — Pro included — gets the free MapLibre + OpenFreeMap engine instead of billed Mapbox GL. Nothing counts against the quota while it's on.

Monthly Mapbox limit

Once this many loads are counted, non-Pro visitors drop to the free map for the rest of the month. Setting a value here pins the ceiling — it overrides whatever the tracker requests.

Reset this month's counter

Zeroes the load count for the current month. Only for when the count is wrong (e.g. a bug inflated it) — it does not reset what Mapbox has actually billed.
